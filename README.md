# Bounce Back!

A small browser platformer built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open [index.html](./index.html) in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server
```

Then visit `http://localhost:8000`.

## Controls

- `A` / `D` or `←` / `→` to move
- `W`, `↑`, or `Space` to jump
- `P` or the Pause button to pause/resume
- `R` to restart

Collect the coins, avoid the red enemies, and reach the yellow flag.
